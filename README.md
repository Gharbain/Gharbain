Hey, I'm Abdullah Gharbain.

Systems & Product Engineer · From Embedded Code to Production Products

I build software across the whole stack—from Assembly, binary data, and deeply embedded systems to secure Rust services and polished applications for mobile, web, and desktop.

Good software earns trust at every layer—from the first byte to the final screen.

About me

I have been building software since 2010. My path has never stayed inside one framework or one layer of the stack. In my professional work, I operate close to the machine: deeply embedded systems, Assembly language, binary data, and debugging at the byte level. That work taught me to be exact, patient, and honest about what a system is really doing.

Outside that environment, I build complete products. My work has taken me through mobile, web, backend services, databases, infrastructure, security, observability, billing, realtime systems, media pipelines, and product design. I enjoy owning the difficult space between an idea and a system that can survive real production use.

I am comfortable moving between low-level and high-level problems because I see them as the same responsibility: understand the system, protect the data, and make the experience reliable for the person using it.

The work that defines me

I work with Rust, C, Assembly, Java, JavaScript, TypeScript, SQL, Swift, Bash, HTML, and CSS.

I develop and debug deeply embedded and binary-based systems, including byte-level investigation and low-level failure analysis.

I build cross-platform products with React Native, Expo, React, Next.js, SwiftUI, and Tauri.

I design backend systems around Rust, PostgreSQL, Redis, REST APIs, WebSockets, authentication, authorization, and multi-tenant isolation.

I work across production infrastructure with Docker, Nginx, Linux, GitHub Actions, Cloudflare, Hetzner, Prometheus, Grafana, Loki, MinIO, and AWS SES.

I have implemented product systems involving secure sessions, refresh-token rotation, role-based permissions, media uploads, realtime collaboration, subscriptions, and payments with Stripe.

I care deeply about root-cause debugging, regression testing, data integrity, security boundaries, observability, performance, and recovery under failure.

I build for real devices and real constraints across iOS, Android, phones, tablets, web, and desktop.

What I build

I build systems that cross boundaries: low-level software that must interpret bytes correctly, backend services that must protect data and permissions, and user-facing products that must remain clear and dependable under real conditions.

My end-to-end product work has included multi-account and multi-tenant architecture, realtime messaging, durable media delivery, collaborative tools, task workflows, granular permissions, billing, monitoring, secure infrastructure, and AI-assisted operational reasoning.

How I approach engineering

I do not begin with a patch. I begin by tracing the system until I can explain the failure.

My working principles are simple:

Prove the root cause before changing production code.

Make the smallest change that completely fixes the problem.

Protect security, permissions, historical data, and unrelated behavior.

Test the failure that happened—not only the success path.

Build observable systems that explain what they are doing.

Prefer an honest limitation over a convincing but unreliable shortcut.

I care about performance and capability, but reliability comes first. A powerful system that cannot be trusted is not powerful.
